## Этап 1. Установка системы сборщика

1. Запустить ВМ: `scripts\04-start-vm.ps1`.
2. Установить Ubuntu 24.04 Desktop:
   - язык — русский или английский (на вкус);
   - **Minimal installation** (нам не нужен лишний софт в сборщике);
   - «Erase disk and install Ubuntu» — весь виртуальный диск;
   - пользователь, например `builder`, пароль простой (ВМ локальная).
3. После установки: `sudo apt update && sudo apt full-upgrade -y`.
4. Подключить общую папку:
   ```bash
   sudo usermod -aG vboxsf $USER
   sudo apt install -y virtualbox-guest-utils virtualbox-guest-x11
   ```
   Перезагрузиться. Проверить: `ls /media/sf_work` — должны увидеть `iso`, `build`, `out`.
5. Отключить блокировку экрана и засыпание (иначе сборка прервётся).

**Результат:** гость видит общую папку, система обновлена.

## Этап 3. Первая сборка (почти без изменений)

Цель — отработать процесс, а не получить красивый дистрибутив.

1. Проект: `~/cubic-project` (обязательно ext4, не общая папка).
2. ISO: `/media/sf_work/iso/ubuntu-24.04.5.1-desktop-amd64.iso`.
3. Ничего не меняя, нажать **Generate**.
4. Готовый ISO скопировать в `/media/sf_work/out/`.
5. Создать тестовую ВМ и загрузить этот ISO.

**Результат:** воспроизведённый ISO грузится и работает.

## Этап 4. XFCE и софт

В терминале Cubic (chroot):

```bash
apt update
apt install -y --no-install-recommends xfce4 xfce4-goodies \
  lightdm lightdm-gtk-greeter lightdm-gtk-greeter-settings
```

Дальше — по `docs/remix-checklist.md`. Сначала **добавляем** XFCE рядом с GNOME,
проверяем, и только потом (отдельной сборкой) удаляем GNOME.

**Результат:** live-система стартует в XFCE.

## Этап 5. Брендинг (Neonix)

Готовые файлы — в `branding/neonix/`, в госте — `/media/sf_work/build/neonix`.
Применяется одной командой в chroot:

```bash
bash /media/sf_work/build/neonix/apply-branding.sh
```

- `/etc/os-release`, `/etc/lsb-release`, `/etc/issue`
- имя дистрибутива, логотип, обои
- тема LightDM и Plymouth
- тексты загрузочного меню (через Cubic, вкладка с загрузкой ISO)
- `/etc/skel` — дефолтные настройки XFCE для новых пользователей

**Результат:** система выглядит как отдельный продукт.

4. Проверить, что после установки — XFCE и ваш брендинг.

**Результат:** дистрибутив ставится и работает на «чистой» машине.

## Риски

- **Мало места в ВМ** — проект Cubic занимает 15–20 ГБ. Диск 40 ГБ хватает, но не запускайте несколько проектов сразу.
- **Проект на vboxsf/NTFS** — сборка ломается. Только ext4.
- **Удаление GNOME** — легко утащить нужные зависимости. Делайте это отдельной сборкой и проверяйте.
- **Юридические** — не используйте имя и логотипы Ubuntu.
